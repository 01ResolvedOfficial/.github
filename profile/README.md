01Resolved is the information layer for ownership coins and decision markets. We track onchain ownership assets across the [MetaDAO](https://metadao.fi) and [Backable](https://www.backable.biz) ecosystems: what each asset represents, how value reaches holders, and the evidence behind it.

### What we cover

| | |
|---|---|
| **Treasuries and NAV** | NAV, NAV per share, runway, monthly allowance and the full account registry for every tracked project. |
| **Valuation** | Premium or discount to NAV for every ownership coin, against its own history. |
| **Decision markets** | Live proposals, pass edge, trader alignment and conviction over time. |
| **Launches** | Live and completed raises, returns, contributing wallets, and projects that wound down. |
| **Ownership rights** | What holders are actually entitled to, from published rights records. |
| **Wallets** | Holdings, ICO participation and decision market trading for any wallet. |

### Build with it

The [01Resolved API](https://01resolved.mintlify.app) serves the same data as [01resolved.com](https://www.01resolved.com). To request a key, message us on [Telegram](https://t.me/Official01Resolved) or email team@01resolved.com.

```bash
curl -H "x-api-key: YOUR_API_KEY" \
  "https://api.01resolved.com/v1/global-dashboard/projects-launch"
```
